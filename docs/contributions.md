# 개발 역할과 AI 활용 범위

이 프로젝트는 블로그 운영 중의 필요를 바탕으로, AI 개발 도구와 협업해 만든 개인 포트폴리오입니다. 모든 코드를 혼자 직접 작성했거나 AI 모델을 직접 학습했다고 설명하지 않습니다.

## 사용자 역할

- 블로그 글 중복 확인이라는 문제와 사용 목적 제시
- 실제 네이버 백업 신청·다운로드와 데이터 제공
- 제목에서 본문 비교로 확장, 지속적인 글 등록·수정 요구 제시
- Windows 설치·명령 실행과 실제 화면 테스트
- 잘못된 검색 결과, 실행 아이콘 문제, CMD 창 노출 등 사용 중 발견한 문제 공유
- 한글 화면과 일반 프로그램 같은 실행 방식에 대한 피드백

## AI 개발 도구의 지원

- Python 코드 초안 작성, 기능 구현과 파일 수정
- 라이브러리·모델 사용법 확인과 문제 원인 분석
- 데이터 가져오기, 본문 분할, 저장 구조, 실행 관리 코드 구현
- 테스트 작성·실행, 코드 문법과 공개 패키지 점검
- 화면·아이콘 제작과 문서 정리

## 검토와 검증

사용자는 단계별 실행 화면으로 기능을 확인했고, AI 도구는 별도 테스트 데이터와 실행 제어 테스트를 사용했습니다. 화면 자동 검사 중 완료되지 않은 시도도 있었으므로, 모든 화면이 자동 테스트됐다고 주장하지 않습니다. 실제 사용자 화면 확인과 자동 검증의 범위는 [검증 기록](validation.md)에 구분합니다.

## 사용한 AI

- 개발 지원: 이 대화의 ChatGPT/Codex 기반 AI 개발 도구
- 프로그램 내부: Sentence Transformers의 `paraphrase-multilingual-MiniLM-L12-v2`
- 내부 모델 용도: 문장 임베딩과 유사도 비교
- 수행하지 않은 작업: 모델 학습, 파인튜닝, 한국어 데이터셋 기반 성능 평가

## 포트폴리오에서 설명할 수 있는 경험

실제 문제를 작은 기능으로 나누고, 실행 결과를 확인하면서 요구사항을 구체화한 경험입니다. 특히 AI 점수를 그대로 신뢰하지 않고 누락 사례를 찾아 검색 규칙으로 보완한 점, 새 글의 지속적 관리와 실행·종료까지 사용 흐름을 연결한 점을 설명할 수 있습니다. 구현 세부 사항은 코드를 읽고 본인이 이해한 범위에서 설명하는 것이 적절합니다.
