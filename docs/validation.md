## 공개 패키지 자동 검사

공개 폴더에서 기존 개발용 Python 3.11.9 가상환경을 사용해 아래 명령을 실행했습니다.

```bat
python -X utf8 -m unittest discover -s tests -v
```

**결과: 12개 통과, 실패 0개, unittest 표시 시간 0.226초.** 패키지 설치 시간·모델 로딩 시간·검색 속도를 의미하지 않습니다. 새 PC에서 새 가상환경을 설치한 검사는 아닙니다.

## 실행 관리 검사

개발 환경에서 `launcher.pyw --no-browser`로 브라우저를 열지 않고 실행 제어를 확인했습니다.

- 숨김 실행 프로세스와 Streamlit 준비 상태 확인
- 두 번째 실행이 새 서버를 만들지 않고 같은 자식 프로세스를 재사용
- 토큰 없는 종료 요청 거부
- 유효한 종료 요청 뒤 서버와 실행 정보 정리

이 과정에서 Windows의 중복 바인딩 문제를 발견해 전용 주소 사용 설정을 수정하고 재검사했습니다. 이 검사는 화면 버튼의 모든 UI 동작과 타 PC 설치까지 보장하지 않습니다.

## 미검증 또는 제한된 범위

- 별도 PC의 신규 설치, 여러 Windows 버전, VBS 비활성화 환경
- 모델 변경·업데이트 시 검색 품질과 캐시 호환성
- 정량 검색 평가와 임계값 최적화
- 모든 HTML 변형, 이미지 OCR, 표 구조 보존
- 장시간 사용·대규모 데이터·동시 사용자 부하
- 공개 서버 보안과 사용자 인증
- 모든 화면에 대한 자동 UI 회귀 검사

화면 자동 검사 중 완료되지 않은 시도는 성공으로 세지 않았습니다. 사용자 화면에서 확인한 항목과 자동 검사를 구분했습니다.
